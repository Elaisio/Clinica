# Centro Médico Especializado Gelvisol - Website Estático

Website oficial do **Centro Médico Especializado Gelvisol** em Luanda, Angola, desenvolvido exclusivamente em **HTML5, CSS3 e JavaScript Puro (Vanilla JS)**.

## 🚀 Como Executar / Publicar

Este website é **100% estático**, o que significa que não requer Node.js, npm, frameworks ou configurações de servidor complexas:

1. **No seu computador (Uso Local):**
   - Dê um duplo clique no ficheiro `index.html` para abrir diretamente no Google Chrome, Edge, Safari, Firefox ou qualquer outro navegador.

2. **Na sua Hospedagem Web (cPanel, Apache, Nginx, Hostinger, Vercel, Netlify, GitHub Pages, etc.):**
   - Envie todos os ficheiros desta pasta (`index.html`, `style.css`, `script.js` e as imagens `.png`/`.svg`) diretamente para a pasta pública do seu servidor (ex: `public_html/`).

## 📁 Estrutura de Ficheiros

- `index.html` — Estrutura completa organizada em 5 secções essenciais: 1. Início, 2. Apresentação & Valores, 3. Especialidades (18 especialidades com novo SVG de Dermatologia), 4. Cirurgia & Internamento VIP, e 5. Contactos & Agendamento.
- `style.css` — Folha de estilos em CSS puro com variáveis, layout responsivo e transições.
- `script.js` — Lógica em JavaScript puro para pesquisa/filtros de especialidades, menu mobile, modal de agendamento e integração com WhatsApp.
- `sala.png` — Imagem principal da recepção e sala de espera.
- `consultorio.png` — Imagem institucional do consultório médico e atendimento.
- `colsutorio.png` — Imagem do bloco operatório de alta tecnologia.
- `sala-vip.png` — Imagem dos quartos de internamento VIP.
- `logo.png` — Imagem oficial do logótipo da clínica Gelvisol.
